## 清单外仍保留的验证边界

上述五组验收已完成，不再保留为待用户确认；以下原有专项不因本次反馈自动通过：

- Preview 固定动画/后端的开关对照、DWM/RDP 与 I/O/帧率量化采样、原生 job/映射回收明细，
  以及游戏最小化、GUI 页面与显隐、多轮重连等未在本次清单中逐项确认的边界。
- Onboarding 多 DPI/跨屏、系统动画开关、Tab 焦点遍历、原生标题栏/托盘及已有 Session 恢复专项。
- Updater 无法确认环境退出时阻止安装的故障场景；已有 Child Session 恢复仍沿用此前暂缓决定。
- 本地 Worker 双进程完整帧自检超时仍未解决；本次没有重跑自动化，也未核对实测 Worker 是否包含
  此前尚未部署的简化改动。实测结论适用于用户所测安装包，不自动扩展为当前源码全量构建通过。
