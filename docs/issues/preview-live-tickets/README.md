## 规格覆盖

| 父规格内容 | 主要负责工单 |
| --- | --- |
| Worker 采集所有权、核心协议、BGR32、文件映射、位图显示 | 01 |
| 目标身份、等待与失效、游戏重开、暂时失败和最小化 | 02 |
| 可见性、租约、当前连接、重订阅、正常回收与残留清理 | 03 |
| 任务前后持续预览、Stop 语义、原生调用阻塞与恢复交错 | 04 |
| 真实跨 Session 权限、隐藏 RDP、设备资源、完整包及长期验收 | 05 |

公共约束对每张均有效：不修改 MaaNOP 截图后端，不新增进程、不增加高清/多窗口/录制，
不改变已验证 Child Session 和任务生命周期，不设置 CPU/内存硬门槛，也不忽略已知持续资源增长。
未执行的验收必须明确标为待验收，ready-for-agent 不表示验证通过。
